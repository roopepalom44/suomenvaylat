## Suomenväylät QGIS 0.1.0 — esijulkaisu

Asenna lataamalla `Suomenvaylat-QGIS-0.1.0.zip` ja valitsemalla QGISissä **Lisäosat → Hallitse ja asenna lisäosia → Asenna ZIP-tiedostosta**. Vaatii QGIS 3.44:n.

Tässä versiossa toimivat WFS- ja OGC API Features -aineistojen haku aluerajauksella, hallinnolliset alueet, Kapsin GeoTIFF-lataus, OSM:n Overpass-haku sekä Kapsin ja MML:n taustakarttatasot. QGIS 3.44:ssä on testattu viiden WFS-lähteen tasoluettelot, Väylän rajattu lataus, Kapsin rasterilataus, OSM:n rajattu lataus, OGC-sivutus sekä MML-vektoritiilitason määritys ilman oikeaa API-avainta.

**Tämä ei vielä ole toiminnallisesti identtinen ArcGIS Pro -version kanssa.** Aino WMS ja MML Karttakuva puuttuvat, ja eri lähteitä käsitellään erillisinä ajoina. Tarkempi tilanne: [QGIS-ohje](https://github.com/roopepalom44/suomenvaylat/blob/main/qgis_plugin/README.md).
